Custom Deck:
To install the custom deck, click on Card Database > Open custom sets folders and place the .xml file in there.

Deck list:
To add the deck with printings selected, place the .cod in ..\AppData\Local\Cockatrice\Cockatrice\decks
Even with the custom printings selected in a deck, Cockatrice won't always show it. To fix this you can click on Card Database > Manage Sets and click and drag the set to the top of the list to give it priority, this will need to be done whenever a new set releases.
